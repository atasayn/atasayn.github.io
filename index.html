IEDC — Industrial Ecology Data Commons
University of Freiburg · IT Department · 2022 – ongoing
+

The IEDC is an open science database portal for industrial ecology and socio-metabolic research at the University of Freiburg, hosting 400+ datasets for researchers and institutions worldwide. I contributed across the full stack — from database architecture and backend services to the web interface, search features, deployment, and day-to-day technical support.

🗄️
Database Architecture & Backend

MySQL · .NET Backend

C# · HTML · CSS · JavaScript

REST APIs · SQL Queries
