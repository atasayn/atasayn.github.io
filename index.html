LLM-Based Label Matching Visit site
University of Freiburg · Industrial Ecology · 2022 – ongoing
+

The LLM-Based Label Matching Tool is a semantic search utility built into the IEDC portal, helping researchers match labels from new datasets to standardised IEDC vocabulary. I designed and built the full tool — from the embedding pipeline and binary precomputation to the web interface, batch Excel processing, and result export.

🧠
Semantic Matching Engine

Implemented the label matching pipeline using nomic-embed-text embeddings to surface the most semantically similar IEDC labels for any given input.

Ollama · NLP · nomic-embed-text
📂
Batch Processing

Implemented an Excel upload workflow that processes entire columns of labels at once, returning a ranked match table downloadable as .xlsx.

C# · ASP.NET · Excel
🖥️
Web Interface Development

Designed and developed the full frontend and backend of the tool, including tabbed layout, partial-page updates, loading states, and inline results display.

ASP.NET · C# · JavaScript · CSS
🗄️
Embedding Precomputation

Precomputed and serialised vector embeddings for all IEDC labels across six classifications into binary files, keeping query response times fast.

Vector Embeddings · Binary Serialisation
✅
Validation & UX

Added input validation, error handling, file format checks, and user-friendly feedback — ensuring the tool degrades gracefully and guides users when something goes wrong.

UX · Input Validation · Error Handling
